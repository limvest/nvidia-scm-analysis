## 1. 스크리닝 방법론

### 복합 점수 산식

```
grade_score = {A:6, B:5, C:4, D:3, E:2, F:1}

quality = (grade/6)*40 + (OPM/60)*20 + (nv_exp/100)*20 + (min(switch_mo, 36)/36)*20
value_score = max(0, 100 - ev_ebitda*1.5)    # ev_ebitda < 150 시
net_cash_bonus = min(20, abs(debt_ratio)*5)   # debt_ratio < 0 시 (순현금)

composite = quality * (1 + value_score/100) + net_cash_bonus
```

- **grade**: SCM 초크포인트 등급 (A=독점 단일공급, B=과점, C=주요공급사)
- **nv_exp**: NVIDIA 매출 의존도 추정치 (0~100)
- **switch_mo**: 공급사 전환에 필요한 월수

### 4-1. Lasertec (TSE: 6920) — #1 복합점수

**한 줄 요약:** EUV 패턴 마스크 검사 유일 공급사. 순현금 + -55% 낙폭 + High-NA 교체수요 대기.

#### 비즈니스 & 해자

- **제품**: ABICS(EUV 블랭크 검사) + ACTIS(EUV 패턴 마스크 검사)
- **시장점유율**: EUV 마스크 검사 장비 ~58% (KLA 34%). 단, **어크티닉 패턴 검사는 Lasertec 유일**
- **진입장벽**: 자체 개발 13.5nm EUV 광원 "URASHIMA" — DUV/전자빔으로는 매립 위상 결함 검출 불가. 10년+ 기술 선행
- **HOYA 의존성**: HOYA EUV 블랭크 공장의 핵심 QC 게이팅 → Lasertec 공급 중단 시 HOYA 블랭크 생산 수 주 내 정지

#### Rubin SCM 연결

`NVIDIA Rubin (TSMC N2) → EUV 리소그래피 → EUV 포토마스크 → Lasertec ABICS/ACTIS 검사`

Rubin 생산에 사용되는 모든 EUV 마스크는 Lasertec 장비 통과 필수. 대체재 없음.

**SCM 충격 타임라인:** 0-4주 재고 버퍼 → 1-3개월 수율 저하 → **3-6개월 TSMC N2/Rubin 생산 제약**

`ASML EUV → EUV 마스크 블랭크 (AGC 59%) → 포토마스크 샵 → TSMC → Rubin`

**SCM 충격 타임라인: 4-8주** — 마스크 샵(Toppan, DNP, Photronics)의 블랭크 재고 2-6주. AGC 공급 중단 시 Hoya 34% 단독으로 흡수 불가. **전 세계 EUV 기반 첨단 공정 4-8주 내 정지.**

High-NA EUV 채택 시 새 블랭크 스펙 필요 → 추가 인증 사이클 → AGC 선행 개발 중.

4. **일본 TSE 관행** — 사업부 분리 발표 없이는 재평가 없음

**Bull:** Electronics 사업부 분리/상장 발표 시 즉각 재평가. Electronics만 15x EV/E 적용 시 임플라이드 가치 = 전체 EV의 50%. High-NA 블랭크 개발 완료 시 ASP 상승.

**Bear:** 생명과학 추가 손상차손 위험. 디스플레이 유리 구조적 약세. 반도체는 매출의 ~18% — 재평가 촉매 없이 제한적.
